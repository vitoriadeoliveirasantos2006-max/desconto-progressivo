# Sistema de Desconto Progressivo

Programa desenvolvido em **Python** para calcular descontos de acordo com o valor total de uma compra.

## Regras de desconto

* Compras abaixo de **R$ 200,00** → 5% de desconto
* Compras de **R$ 200,00 a R$ 299,99** → 10% de desconto
* Compras a partir de **R$ 300,00** → 15% de desconto

## Como executar

1. Execute o arquivo
2. Digite o valor total da compra.
3. O programa mostrará o valor do desconto e o total a pagar.
